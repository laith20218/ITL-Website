المقدمة 01

١. مقدمة — بنية المشروع

موقع ITL مبني على أحدث التقنيات العالمية لضمان الأداء العالي والأمان والقابلية للتوسع. تستطيع إدارة كل المحتوى — الخدمات، المقالات، الرسائل — من خلال لوحة تحكم ويب سهلة دون الحاجة لأي معرفة برمجية.

١.١ مكدس التقنيات المستخدمة

الطبقةالتقنيةالوظيفة
الواجهة الأماميةNext.js 16 + React 19واجهة المستخدم والصفحات
التصميمTailwind CSS 4 + shadcn/uiالتنسيق والمكونات الجاهزة
قاعدة البياناتPrisma ORM + SQLiteتخزين الخدمات والمقالات والرسائل

١.٢ المتطلبات الأساسية للنشر

  • حساب Vercel — منصة النشر الموصى بها (مجاني للمشاريع الصغيرة) على vercel.com
  • مستودع GitHub — لرفع الكود ومزامنته مع منصة النشر
  • نطاق (Domain) — اختياري، يمكن شراؤه من Namecheap أو GoDaddy أو Google Domains
  • Node.js 20+ — مطلوب فقط إذا كنت ستعمل على الكود محليًا
  • متصفح حديث — Chrome أو Firefox أو Safari لإدارة لوحة التحكم

التشغيل المحلي 02

٢. التشغيل المحلي

قبل النشر على الإنترنت، قد ترغب في تجربة الموقع محليًا لإجراء تعديلات على الكود أو إضافة محتوى أولي. هذه الخطوات اختيارية لمن يريد فقط النشر.

٢.١ تثبيت المتطلبات

1

تثبيت Node.js

حمّل الإصدار 20 أو أحدث من nodejs.org وثبّته على جهازك. للتحقق:

node --version
npm --version
2

تثبيت Bun (مدير الحزم السريع)

المشروع يستخدم Bun بدلاً من npm لسرعة أكبر:

curl -fsSL https://bun.sh/install | bash
3

تنزيل المشروع وتثبيت التبعيات

git clone <repository-url> itl-website
cd itl-website
bun install
4

إعداد متغيرات البيئة

أنشئ ملف .env في جذر المشروع:

DATABASE_URL="file:./db/custom.db"
AUTH_SECRET="your-very-secret-key-change-this"

ثم شغّل أوامر قاعدة البيانات:

bun run db:push     # إنشاء الجداول
bun run scripts/seed.ts  # إضافة البيانات الأولية
5

تشغيل خادم التطوير

bun run dev

سيفتح الموقع على http://localhost:3000 — استخدم متصفحك لمعاينته.

للتحقق من نجاح التثبيت

افتح المتصفح على العنوان أعلاه، يجب أن تظهر الصفحة الرئيسية باللغة الفاخرة بالأسود والذهبي. للدخول إلى لوحة التحكم، انتقل إلى /admin-login واستخدم: demo@itl.com / demo1234.

النشر على الإنترنت 03

٣. النشر على الإنترنت

توجد ثلاث طرق رئيسية لنشر الموقع، مرتبة حسب السهولة والتكلفة. نوصي للمبتدئين بـ Vercel لأنها الأسهل والأسرع.

٣.١ الطريقة الأولى — Vercel (موصى بها)

Vercel هي المنصة الرسمية لـ Next.js وتقدم خطة مجانية كافية لمعظم المواقع. النشر يتم في دقائق عبر ربط مباشر مع GitHub.

1

إنشاء مستودع GitHub

ادخل إلى github.com وأنشئ مستودعًا جديدًا (New Repository) باسم itl-website. ارفع كامل ملفات المشروع إليه.

2

التسجيل في Vercel

ادخل إلى vercel.com واضغط "Sign Up" ثم اختر "Continue with GitHub" لربط حساب GitHub الخاص بك.

3

استيراد المشروع

من لوحة Vercel اضغط "New Project" → اختر مستودع itl-website → اضغط "Import".

4

إعداد متغيرات البيئة

قبل الضغط على Deploy، افتح قسم "Environment Variables" وأضف:

DATABASE_URL="file:./db/custom.db"
AUTH_SECRET="اكتب-كلمة-سر-عشوائية-طويلة-هنا"

لإنشاء AUTH_SECRET قوي، استخدم: openssl rand -base64 32

5

إعداد أوامر البناء

في قسم "Build & Output Settings"، تأكد من الإعدادات التالية:

  • Build Command: next build
  • Output Directory: يُكشف تلقائيًا
  • Install Command: bun install أو npm install
6

النشر!

اضغط "Deploy" وانتظر 2-4 دقائق. ستحصل على رابط مؤقت مثل itl-website.vercel.app. كل تعديل على GitHub سيُحدّث الموقع تلقائيًا.

⚠️ مشكلة قاعدة البيانات على Vercel

Vercel بيئة serverless لا تحتفظ بالملفات محليًا. لذلك SQLite (الذي نستخدمه) سيُعاد إنشاؤه مع كل نشر، ما يعني فقدان البيانات. الحل: استخدم قاعدة بيانات سحابية مثل PlanetScale أو Neon PostgreSQL (مجانية)، ثم عدّل prisma/schema.prisma لتغيير الـ provider من sqlite إلى mysql أو postgresql.

النشر — Netlify 03

٣.٢ الطريقة الثانية — Netlify

Netlify بديل ممتاز لـ Vercel بنفس آلية العمل. خطة المجانية تكفي للمواقع الصغيرة والمتوسطة.

1

التسجيل والاستيراد

ادخل إلى netlify.com → "Add new site" → "Import an existing project" → اختر GitHub.

2

إعدادات البناء

  • Build command: npm run build
  • Publish directory: .next

أضف Plugin اسمه @netlify/plugin-nextjs لتعمل صفحات Next.js بشكل صحيح.

3

متغيرات البيئة

من "Site settings" → "Environment variables" أضف نفس المتغيرات المذكورة في Vercel.

4

النشر

اضغط "Deploy site" — ستحصل على رابط مثل itl-website.netlify.app.

٣.٣ الطريقة الثالثة — VPS (متقدم)

إذا أردت تحكمًا كاملًا، استأجر خادمًا افتراضيًا (VPS) من DigitalOcean أو Linode أو Hetzner بدءًا من 5$/شهر.

1

تثبيت المتطلبات على الخادم

sudo apt update && sudo apt install -y nodejs npm nginx
curl -fsSL https://bun.sh/install | bash
sudo npm install -g pm2
2

نسخ المشروع وتشغيله

git clone <repo-url> /var/www/itl
cd /var/www/itl
bun install
bun run db:push
bun run scripts/seed.ts
bun run build
pm2 start "bun run start" --name itl
3

إعداد Nginx كوكيل عكسي

server {
  listen 80;
  server_name your-domain.com;
  location / {
    proxy_pass http://localhost:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
  }
}
✅ ميزة VPS

على VPS يمكنك استخدام SQLite مباشرة دون مشاكل لأن الملفات تبقى ثابتة. كما أن لديك تحكمًا كاملًا بالأمان والنسخ الاحتياطي.

ربط النطاق 04

٤. ربط النطاق المخصص (Domain)

بعد النشر، ستحصل على رابط فرعي مثل itl-website.vercel.app. للاحتراف، يُفضّل ربط نطاق مخصص مثل itl-team.com.

٤.١ شراء النطاق

اشترِ النطاق من أحد المزودين الموثوقين:

  • Namecheap — namecheap.com — أسعار تبدأ من 8$/سنة
  • Cloudflare Registrar — cloudflare.com — أرخص بدون رسوم مخفية
  • Google Domains — domains.google — واجهة سهلة (انتقل إلى Squarespace)
  • GoDaddy — godaddy.com — معروف لكن أغلى

٤.٢ ربط النطاق بـ Vercel

1

إضافة النطاق في Vercel

من لوحة Vercel → اختر مشروعك → "Settings" → "Domains" → أضف itl-team.com و www.itl-team.com.

2

تحديث سجلات DNS

ادخل إلى لوحة تحكم مزود النطاق وأضف السجلات التالية:

النوعالاسمالقيمة
A@76.76.21.21
CNAMEwwwcname.vercel-dns.com
3

الانتظار للتفعيل

يستغرق تحديث DNS من بضع دقائق إلى 24 ساعة. سيتحقق Vercel تلقائيًا ويفعّل شهادة SSL مجانية من Let's Encrypt.

٤.٣ إعداد البريد الإلكتروني (اختياري)

لإنشاء بريد مثل info@itl-team.com، استخدم:

  • Zoho Mail — مجاني حتى 5 حسابات
  • Google Workspace — 6$/شهر لكل حساب
  • Cloudflare Email Routing — مجاني، يحوّل البريد إلى حسابك الحالي
بعد ربط البريد

حدّث معلومات التواصل في الموقع من خلال تعديل src/components/itl/contact.tsx و footer.tsx لاستبدال info@itl-team.com ببريدك الفعلي.

لوحة تحكم المشرف 05

٥. لوحة تحكم المشرف

لوحة التحكم هي قلب إدارة الموقع. من خلالها تستطيع إدارة الخدمات والمقالات والرسائل دون الحاجة لأي معرفة برمجية. هذا الفصل يشرح كل قسم بالتفصيل.

٥.١ الدخول إلى لوحة التحكم

  1. افتح المتصفح وانتقل إلى https://your-domain.com/admin-login
  2. أدخل البريد الإلكتروني وكلمة المرور
  3. اضغط "دخول لوحة التحكم"
  4. سيتم تحويلك تلقائيًا إلى /admin/dashboard
⚠️ الأمان أولًا

بعد أول تسجيل دخول، غيّر كلمة المرور فورًا من خلال إنشاء حساب جديد أو تعديل قاعدة البيانات مباشرة. لا تترك demo1234 ككلمة مرور على الموقع المنشور.

٥.٢ الصفحة الرئيسية للوحة (Dashboard)

تعرض هذه الصفحة نظرة عامة سريعة على حالة الموقع:

  • بطاقات الإحصائيات: عدد الخدمات، المقالات، الرسائل الإجمالية، الرسائل الجديدة، المستخدمين
  • آخر الرسائل: أحدث 5 رسائل وصلت من نموذج التواصل
  • الطلبات حسب الخدمة: رسم بياني يوضح أي الخدمات تطلب أكثر
  • آخر المقالات: جدول بأحدث 5 مقالات مع حالتها ومشاهداتها

٥.٣ إدارة الخدمات

من قسم "الخدمات" تستطيع التحكم الكامل بالخدمات المعروضة في الصفحة الرئيسية وصفحة التفاصيل المستقلة لكل خدمة.

إضافة خدمة جديدة

  1. اضغط زر خدمة جديدة في أعلى الصفحة
  2. املأ الحقول التالية:
    • عنوان الخدمة — الاسم الذي سيظهر للزوار
    • المعرّف (slug) — أحرف لاتينية بلا مسافات، يُستخدم في الرابط: /services/your-slug
    • الفئة — تصنيف الخدمة (مثل: البحث العلمي، الترجمة)
    • الأيقونة — اختر من القائمة المنسدلة
    • الوصف — فقرة تعريفية تظهر في الصفحة الرئيسية وصفحة التفاصيل
    • المميزات — سطر لكل ميزة (سطر فارغ يُحذف تلقائيًا)
    • الترتيب — رقم يحدد ترتيب الظهور (الأصغر أولًا)
  3. اضغط "حفظ" — ستظهر الخدمة فورًا في الموقع

تعديل خدمة

  1. اضغط زر تعديل على الخدمة المطلوبة
  2. عدّل الحقول التي تريد تغييرها
  3. اضغط "حفظ" — التحديث فوري على الموقع

حذف خدمة

  1. اضغط أيقونة سلة المهملات بجانب الخدمة
  2. أكد الحذف في النافذة المنبثقة
  3. تنبيه: الحذف نهائي ولا يمكن التراجع عنه
لوحة التحكم — المقالات 05

٥.٤ إدارة المقالات

المدونة قسم أساسي لجذب الزوار عبر محركات البحث. كل مقال له صفحة مستقلة تُفهرس تلقائيًا.

إنشاء مقال جديد

  1. اضغط مقال جديد
  2. املأ الحقول:
    • العنوان — عنوان جذاب يصف المحتوى
    • المعرّف (slug) — رابط المقال، مثل research-methodology
    • الفئة — تصنيف المقال (يظهر في فلتر البحث)
    • الكاتب — اسم كاتب المقال (افتراضي: فريق ITL)
    • الوسوم — كلمات مفتاحية مفصولة بفواصل لتحسين SEO
    • الملخص — فقرة قصيرة تظهر في بطاقة المقال
    • المحتوى — النص الكامل، استخدم سطرًا فارغًا للفصل بين الفقرات
    • الحالة — منشور (مرئي) أو مسودة (محفوظ غير منشور)
  3. اضغط "حفظ"

نصائح لكتابة مقالات فعّالة

  • اكتب عناوين تحتوي على كلمات يبحث عنها جمهورك المستهدف
  • الملخص يجب أن يكون 2-3 أسطر تشوق القارئ للدخول
  • قسّم المحتوى إلى فقرات قصيرة (3-5 أسطر) لسهولة القراءة
  • أضف 3-5 وسوم مرتبطة بموضوع المقال
  • انشر مقالًا واحدًا على الأقل أسبوعيًا لتحسين ترتيب الموقع

٥.٥ صندوق الرسائل

كل رسالة تُرسل من نموذج التواصل في الصفحة الرئيسية تصلك هنا. تستطيع إدارتها بشكل احترافي.

تنظيم الرسائل

  • الكل — كل الرسائل بغض النظر عن حالتها
  • جديدة — رسائل لم تُقرأ بعد (تظهر بحدّ ذهبي)
  • مقروءة — رسائل فتحتها لكن لم ترد عليها
  • تم الرد — رسائل أنهيت التعامل معها
  • مؤرشفة — رسائل لا تحتاج لرد لكن تحتفظ بها

الإجراءات المتاحة

  • فتح الرسالة: اضغط عليها لرؤية كل التفاصيل
  • الرد عبر البريد: زر يفتح برنامج البريد لديك جاهزًا للرد
  • تغيير الحالة: ضع كـ "تم الرد" أو "أرشفة"
  • حذف: حذف الرسالة نهائيًا
💡 نصيحة سير العمل

افتح الرسائل الجديدة يوميًا، ارد على المهملة في نفس اليوم إن أمكن، ثم ضعها في "تم الرد". هذا يبني صورة احترافية للفريق ويزيد فرص تحويل الاستفسارات إلى عملاء.

الصيانة والأمان 06

٦. الصيانة والنسخ الاحتياطي والأمان

الموقع كأي نظام يحتاج صيانة دورية لضمان استمراريته وأمانه. هذا الفصل يغطي أهم الممارسات.

٦.١ النسخ الاحتياطي الدوري

قاعدة البيانات تحتوي على كل خدماتك ومقالاتك ورسائل عملائك — فقدانها يعني فقدان ساعات من العمل. اعمل نسخة احتياطية أسبوعيًا على الأقل.

طريقة النسخ (VPS أو محلي)

# نسخ قاعدة البيانات
cp db/custom.db backups/custom-$(date +%Y%m%d).db

# ضغط النسخة
gzip backups/custom-20260628.db

# رفع النسخة إلى تخزين سحابي (اختياري)
aws s3 cp backups/ s3://itl-backups/ --recursive

طريقة النسخ (Vercel + قاعدة بيانات سحابية)

إذا استخدمت PlanetScale أو Neon، تستطيع جدولة نسخ احتياطي تلقائي من لوحة تحكمها. معظمها توفر نسخًا يوميًا تلقائيًا في الخطط المدفوعة.

٦.٢ تغيير كلمة مرور المشرف

لا توجد صفحة لتغيير كلمة المرور في لوحة التحكم الحالية. لتغييرها:

  1. افتح terminal على الخادم
  2. شغّل سكربت تغيير كلمة المرور (سيتوفر قريبًا)
  3. أو عدّلها مباشرة في قاعدة البيانات بكود مشابه:
// في مشروع Node
import { scryptSync, randomBytes } from 'crypto';
const salt = randomBytes(16).toString('hex');
const hash = scryptSync('new-password', salt, 64).toString('hex');
console.log(`${salt}:${hash}`);
// ثم ضع الناتج في حقل password للمستخدم

٦.٣ تحديث الموقع

لتحديث الموقع بميزات جديدة أو إصلاحات:

  1. ادخل التعديلات على الكود محليًا
  2. اختبرها بـ bun run dev
  3. ارفعها إلى GitHub: git push origin main
  4. Vercel/Netlify سيعيد النشر تلقائيًا خلال 2-3 دقائق

٦.٤ مراقبة الأداء

  • Google Analytics — مجاني، يعرض عدد الزوار ومصادرهم
  • Vercel Analytics — مدمج في Vercel، يظهر أداء الصفحات
  • Google Search Console — لمراقبة ظهور الموقع في نتائج البحث
  • UptimeRobot — مجاني، يراقب توقف الموقع ويرسل تنبيهات

٦.٥ ممارسات أمان أساسية

  • لا تشارك كلمة مرور المشرف مع أحد — أنشئ حسابات منفصلة لكل عضو
  • فعّل المصادقة الثنائية على GitHub و Vercel
  • راقب رسائل التواصل بشكل دوري لرصد أي محتوى مشبوه
  • حدّث التبعيات شهريًا: bun update
  • تجنّب رفع ملف .env إلى GitHub — تأكد أنه في .gitignore
الأسئلة الشائعة 07

٧. الأسئلة الشائعة

س: كيف أضيف صفحة جديدة للموقع؟

إضافة صفحة جديدة تتطلب معرفة برمجية بسيطة. أنشئ ملفًا في src/app/your-page/page.tsx وستظهر تلقائيًا على /your-page. للروابط في القائمة، عدّل src/components/itl/header.tsx.

س: كيف أغيّر الألوان أو الخطوط؟

كل الألوان معرّفة في src/app/globals.css ضمن المتغيرات --gold و --gold-soft و --gold-deep و --background. غيّر قيمها لتغيير الهوية البصرية كاملة. الخطوط معرّفة في src/app/layout.tsx.

س: ماذا لو نسيت كلمة مرور المشرف؟

لديك خياران: (١) الوصول إلى قاعدة البيانات مباشرة وإعادة تعيين كلمة المرور يدويًا باستخدام سكربت الـ hash الموجود في src/lib/auth.ts. (٢) إعادة تشغيل سكربت scripts/seed.ts بعد تعديل بيانات المستخدم التجريبي — لكن هذا سيمسح البيانات الأخرى.

س: هل يدعم الموقع أكثر من لغة؟

حاليًا الموقع عربي فقط بدعم RTL كامل. لإضافة لغة ثانية، يلزم تعديل البنية وإضافة مكتبة مثل next-intl (مثبتة بالفعل في المشروع) وترجمة كل النصوص.

س: كيف أحسن ظهور الموقع في جوجل؟

الموقع مهيّأ تقنيًا لـ SEO عبر Next.js (Meta tags ديناميكية، روابط نظيفة، سرعة عالية). للمزيد: انشر مقالات عالية الجودة بانتظام، أضف وصفًا (Meta Description) لكل مقال، أنشئ حساب Google Search Console وأضف خريطة الموقع، واكسب روابط خلفية من مواقع موثوقة.

س: ما عدد الزوار الذين يتحملهم الموقع؟

على خطة Vercel المجانية: حوالي 100,000 زيارة شهريًا. على خطة Pro (20$/شهر): مليون+. على VPS: يعتمد على مواصفات الخادم، خادم بـ 5$ يكفي لعشرات الآلاف يوميًا.

س: كيف أضيف Google Analytics؟

أنشئ حسابًا على Google Analytics، احصل على معرّف القياس (مثل G-XXXXXXX)، ثم أضف مكوّن Google Analytics في src/app/layout.tsx. راجع توثيق Next.js لتفاصيل التركيب.

س: الموقع بطيء، ما الحل؟

تحقق من: (١) حجم الصور — استخدم تنسيق WebP. (٢) عدد المكونات في الصفحة الرئيسية. (٣) استخدم أداة PageSpeed Insights لتحليل الأداء وتحديد المشاكل بدقة.

بعد نشر الموقع، ركّز على: (١) إضافة صور حقيقية للخدمات والفريق. (٢) كتابة مقال أسبوعي. (٣) الرد على الرسائل خلال 24 ساعة. (٤) مراقبة Google Search Console أسبوعيًا. هكذا يكبر موقعك ويزداد تأثيره.
